# AI 注册服务说明

本文介绍通过本群 **AI 助手** 办理香港公司注册的整体流程、常用指令与常见问题。客户无需安装额外软件，在企微客户群内即可完成材料咨询与资料提交。

---

## 一、什么是 AI 注册

**AI 注册** 是指由智能助手协助您完成香港有限公司注册的前期工作：

1. **材料咨询** — 在群内直接提问，AI 根据知识库解答注册地址、董事股东、ICRIS 材料等问题
2. **在线填表** — 通过 H5 表单或群内粘贴键值对提交资料
3. **材料收集** — 上传身份证、地址证明等文件，系统自动归类并显示进度
4. **人工复核** — 材料齐全后确认，专员接手 ICRIS 系统提交等后续步骤

AI 负责 **解答与收集**；最终向政府系统 **正式递交** 仍由持牌专员或内部同事完成，确保合规。

## 二、入群后怎么用

### 1. 自动欢迎

企业成员创建客户群并拉您入群后，系统会自动发送：

- 欢迎说明
- 《香港公司注册材料清单》
- 在线填表链接

若未收到，可发送 **`/资料`** 重新获取清单。

### 2. 常用指令

| 指令 | 作用 |
|------|------|
| `/资料` 或 `/docs` | 重新发送材料清单 |
| `/填表` 或 `/form` | 获取在线填写链接 |
| `/进度` 或 `/progress` | 查看当前材料收集进度 |
| `确认` | 材料齐全后确认，启动注册流程 |
| `转人工` | 暂停 AI，通知专员人工跟进 |

### 3. 直接提问

除指令外，您可以用自然语言提问，例如：

- 「注册地址可以用大陆地址吗？」
- 「董事和股东可以是同一个人吗？」
- 「ICRIS 账号怎么注册？」
- 「PO Box 能不能做公司地址？」

AI 会结合知识库检索后回答。**请尽量一次说清问题**；连续多条消息会自动合并后统一回复（约 5 秒防抖）。

### 4. 提交资料

**方式 A：在线表单**

发送 `/填表` 获取链接，在浏览器中填写中英文姓名、地址、股份等信息。

**方式 B：群内粘贴**

按「字段名=内容」格式粘贴，例如：

```
英文姓氏=Chan
英文名字=Tai Man
电邮=example@email.com
香港电话=91234567
```

系统会自动解析并写入材料库。

**方式 C：上传文件**

在群内发送身份证、护照、地址证明等图片或 PDF，系统按文件名与内容提示归类。


## 四、ICRIS 账号注册（概要）

在香港公司 **电子注册** 前，申请人需先在 **ICRIS**（公司注册处综合资讯系统）注册个人账号：

| 项目 | 要求 |
|------|------|
| 英文姓名 | 与证件一致 |
| 电邮 | 用于接收账号密码，务必可正常收信 |
| 香港电话 | 有效本地号码 |
| 用户名 / 密码 | 密码须 10 位以上、首字母大写、含字母与数字 |
| 身份证明 | 香港身份证或护照；非香港地址需按系统要求填写 |
| 证明文件 | 通常需经核证真实副本（Certified True Copy） |

注册成功后，**账号密码会发到您填写的邮箱**。该账号用于后续在 ICRIS 提交公司注册文件（NNC1 等）。

> 本群 AI 可解答 ICRIS 注册 **需要哪些材料**；具体在官网填表、验证码、提交操作由专员或自动化流程在后台协助，客户无需自行操作浏览器。

## 五、材料要点速查

### 公司注册地址

- 必须是 **香港实际地址**
- **不接受 PO Box（邮政信箱）**
- 可使用商业地址或秘书公司提供的注册地址

### 董事与股东

- 至少 **一名自然人董事**
- 董事与股东 **可以是同一人**，也可以不同
- 股东可以是个人或公司

### 公司秘书

- 须为香港居民或 **持牌秘书公司**
- 秘书地址须为香港地址

### 商业登记证

- 新设公司须一并申请商业登记证
- 有效期可选 **1 年** 或 **3 年**

## 六、AI 能做什么 / 不能做什么

| AI 能做 | AI 不能做 |
|---------|-----------|
| 解答材料与流程问题 | 代替您签署法定文件 |
| 发送清单与填表链接 | 保证政府一定批准公司名 |
| 归类您上传的证件 | 提供法律意见或税务建议 |
| 显示收集进度 | 修改已递交政府的信息 |
| 材料齐后转专员 | 在未经确认时自动提交 ICRIS |

涉及 **费用、加急、特殊股权结构、跨境合规** 等复杂事项，请发送 **`转人工`**。

## 七、常见问题

### Q1：AI 回复慢或没回复？

- 连续提问会合并处理，请等待约 5–10 秒
- 若长时间无回复，可能是系统维护或已转人工，请 `@群主` 或发送 `转人工`

### Q2：AI 回答不对怎么办？

- 发送 `转人工` 由专员纠正
- 也可补充更具体的问题（如公司类型、股东国籍）以便 AI 精准检索

### Q3：材料填错了怎么改？

- 重新发送 `/填表` 打开链接修改
- 或在群内说明需修改的字段，专员协助处理

### Q4：注册大概要多久？

- **材料收集**：取决于客户配合速度，通常数个工作日
- **ICRIS 审批**：政府处理时间以公司注册处为准，一般数个工作日至数周
- 加急需求请 **转人工** 咨询

### Q5：费用多少？

- 政府规费（注册费、商业登记费等）以官网为准
- 秘书服务、地址、代办服务费请向专员索取报价（发送 `转人工`）
