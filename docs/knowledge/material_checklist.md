# 香港公司注册材料清单

您好！以下是注册香港有限公司所需材料，请按清单准备：

## 一、公司基本信息
- 拟用公司名称（中英文各一个，提供 2-3 个备选名）
- 公司注册地址（香港地址，**不接受 PO Box**）
- 公司联络邮箱及香港电话号码

## 二、股东/创办成员资料
- 每位创办成员的中英文姓名
- 身份证明（香港身份证 / 护照复印件）
- 常住地址证明
- 认购股份数目

## 三、董事资料
- 每位董事的中英文姓名
- 身份证明复印件
- 常住地址
- 联络邮箱及电话

## 四、公司秘书资料
- 公司秘书姓名（可为自然人或持牌秘书公司）
- 身份证明 / 牌照证明
- 香港地址

## 五、业务资料
- 业务性质描述
- 商业登记证有效期选择（1 年或 3 年）

## 六、申请人资料（用于注册 ICRIS 账号）
- 申请人中英文姓名
- 身份证明
- 电邮地址（用于接收 ICRIS 账号密码）
- 香港联络电话

## 常见问题

### 注册地址要求
公司注册地址必须是香港实际地址，不能使用邮政信箱（PO Box）。可使用商业地址或秘书公司提供的注册地址。

### 董事与股东
董事和股东可以是同一人，也可以不同。至少需要一名自然人董事。股东可以是个人或公司。

### ICRIS 账号
申请人需先在 ICRIS 系统注册账号，注册成功后账号密码会发送到申请人邮箱，用于后续电子提交公司注册文件。
