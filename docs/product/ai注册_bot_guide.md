# AI 注册服务说明（Bot 产品文档，非 RAG 知识库）

本文介绍通过本群 **AI 助手** 办理香港公司注册的整体流程、常用指令与常见问题。客户无需安装额外软件，在企微客户群内即可完成材料咨询与资料提交。

> 业务话术与步骤注意事项见 [`docs/knowledge/注册.md`](../knowledge/注册.md)（RAG 主知识源）。

---

## 一、什么是 AI 注册

**AI 注册** 是指由智能助手协助您完成香港有限公司注册的前期工作：

1. **材料咨询** — 在群内直接提问，AI 根据知识库解答注册地址、董事股东、ICRIS 材料等问题
2. **群内填表** — 发送 `/填表` 获取填写模板，按「键=值」格式粘贴到本群提交资料
3. **材料收集** — 上传身份证、地址证明等文件，系统自动归类并显示进度
4. **人工复核** — 材料齐全后确认，专员接手 ICRIS 系统提交等后续步骤

AI 负责 **解答与收集**；最终向政府系统 **正式递交** 仍由持牌专员或内部同事完成，确保合规。

## 二、入群后怎么用

### 1. 自动欢迎

企业成员创建客户群并拉您入群后，系统会自动发送 **赢态财务集团专属服务老师（邓老师）** 的问候语；若开启自动清单，还会发送注册资料清单。

- **`/资料`** — 获取《香港公司注册材料清单》
- **`/填表`** — 获取群内粘贴填写模板

### 2. 常用指令

| 指令 | 作用 |
|------|------|
| `/资料` 或 `/docs` | 重新发送材料清单 |
| `/填表` 或 `/form` | 获取填写模板（粘贴到本群提交） |
| `/模板` 或 `/template` | 同 `/填表` |
| `/进度` 或 `/progress` | 查看当前材料收集进度 |
| `确认` | 材料齐全后确认，启动注册流程 |
| `转人工` | 暂停 AI，通知专员人工跟进 |

---

## 三、注册全流程（客户视角）

```
入群 → 赢态服务老师欢迎语（+ 资料清单）
  ↓
咨询材料问题（AI 解答）→ /填表 / 上传证件
  ↓
/进度 → 材料齐全 → 「确认」→ 专员复核 → ICRIS
```
